# 📊 FinSage — Global Financial Intelligence Platform

A professional multi-asset financial analysis dashboard.

**Live App:** *(deploy on Streamlit Cloud)*

## Features
- 🌍 Global Stocks — NSE India, US, UK, Germany, Japan
- ₿ Cryptocurrencies — BTC, ETH, SOL, BNB and more
- 🎭 Meme Coins — DOGE, SHIB, PEPE, FLOKI and more
- 📊 Unified Risk Matrix (1–10 score)
- 🔴 Live price ticker bar
- 📥 Download full analysis report

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## APIs Used (100% FREE)
- **yfinance** — Yahoo Finance (no key needed)
- **CoinGecko** — Free public API (no key needed)
